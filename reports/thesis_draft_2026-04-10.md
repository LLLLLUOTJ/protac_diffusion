# 基于二维条件信息的 PROTAC Linker 生成方法研究

## 摘要

蛋白降解靶向嵌合体（PROTAC）由两端功能片段和中间 linker 构成，其中 linker 不仅承担连接作用，还会影响分子的柔性、空间构象和整体理化性质，因此 linker 设计是 PROTAC 分子优化中的关键问题。与传统小分子生成任务相比，PROTAC linker 生成面临公开数据规模有限、监督信号较弱以及稳定三维结构先验不足等困难，导致现有方法难以直接应用于该任务。针对上述问题，本文聚焦于缺乏稳定三维先验、主要依赖二维结构信息的 PROTAC linker 生成场景，围绕数据构建、结构表示和条件生成方法开展研究。

首先，针对原始 PROTAC 数据难以直接转化为标准条件生成样本的问题，本文基于完整 PROTAC 分子与候选 linker 分子的子结构匹配关系，构建了一套 weak-anchor 数据处理流程。通过唯一匹配、边界约束和片段规模筛选等规则，将完整分子转化为“左片段—anchored linker—右片段”的弱监督样本，为后续训练提供了统一的数据基础。

其次，针对 linker 中间结构具有明显长尾分布、整段 linker 直接建模空间稀疏的问题，本文围绕 linker 中间单元构建表示层。通过对 linker 主链进行切分和 token 化，并引入保留连接方向信息的 oriented token 表示，在此基础上采用“高频片段建库、低频片段映射、任务微调”的分阶段 embedding 学习策略，以提升模型对 linker 常见结构模式和稀有结构模式的统一表示能力。

最后，在统一数据设定下，本文实现了基于 token 的二维条件 PROTAC linker 生成方案，并对不同表示与生成路线进行了实验比较。结果表明，相比原子级图扩散路线，token-based 方法在解码、组装和端到端生成稳定性方面更适合当前弱监督 PROTAC linker 任务；与外部 baseline Link-INVENT 的比较进一步表明，本文方法在结构分布覆盖和任务适配性方面具有一定优势，但在 QED、SA 等药化性质指标上仍存在提升空间。

本文验证了在二维条件和弱监督设定下开展 PROTAC linker 生成研究的可行性，为后续引入更强的性质约束与三维先验提供了基础。

**关键词：** PROTAC；linker 生成；弱监督学习；分子表示学习；token 条件生成

## 第1章 绪论

### 1.1 研究背景

蛋白降解靶向嵌合体（Proteolysis Targeting Chimeras，PROTAC）是一类能够同时结合目标蛋白和 E3 泛素连接酶，并诱导目标蛋白被泛素化降解的双功能分子。与传统抑制剂相比，PROTAC 不仅能够通过“占据驱动”机制调控蛋白功能，还能够通过“事件驱动”方式实现目标蛋白的持续降解，因此在抗肿瘤、神经退行性疾病和免疫调节等领域展现出较高的应用潜力。

从结构上看，PROTAC 分子通常由三部分构成：一端是针对目标蛋白的配体，另一端是针对 E3 泛素连接酶的配体，中间则由 linker 将两端连接起来。相比传统小分子药物，PROTAC 具有分子量大、柔性高、结构复杂等特点，其中 linker 的作用尤为关键。一方面，linker 需要保证左右两端片段在化学上能够被有效连接；另一方面，linker 的长度、柔性和中间结构模式会显著影响整分子的构象、理化性质以及潜在活性。因此，linker 设计不仅是一个连接问题，更是一个直接影响 PROTAC 成药性和功能表现的核心问题。

然而，PROTAC linker 设计的复杂性明显高于普通小分子中的连接子设计。首先，PROTAC 分子往往包含两个较大的功能片段，使得 linker 不仅要满足化学连接要求，还要兼顾整体构象和性质平衡。其次，PROTAC linker 的结构空间较大，长度分布和中间结构模式具有明显多样性，难以通过简单规则进行枚举。再次，公开可用的 PROTAC 数据相比传统小分子数据库更少，能够直接用于监督学习的 linker 级数据更为稀缺。这些因素共同决定了，面向 PROTAC 的 linker 生成需要有针对性的任务建模与数据处理流程。

### 1.2 问题提出

基于上述背景，本文关注的核心问题可以表述为：

> 在缺乏稳定三维先验、公开数据监督较弱的条件下，如何仅基于二维信息实现有效的 PROTAC linker 生成？

围绕这个问题，本文进一步将其拆解为两个更具体的子问题。

第一个子问题是，如何从原始 PROTAC 数据中构造可训练的 linker 条件生成样本。现实数据往往只提供完整 PROTAC 结构，而不直接提供“左右片段到 linker”的标准监督对，因此需要设计一套合理的数据处理流程，将原始数据转化为适用于生成任务的样本表示。

第二个子问题是，如何设计适合 PROTAC linker 的表示与生成方法，使模型既能学习真实结构模式，又能保持生成稳定性。由于 PROTAC linker 的结构模式存在显著长尾，直接进行整段或原子级建模容易导致学习不稳定，因此需要寻找更适合该任务的表示层与生成范式。

### 1.3 研究思路

针对上述问题，本文采用了一条由数据构建、表示学习到条件生成逐步推进的研究思路。

首先，基于完整 PROTAC 分子与候选 linker 的子结构匹配关系，构建 weak-anchor 数据集，将原始数据转化为可用于条件生成训练的样本。该数据集的核心目的是在缺乏强监督标注的条件下，尽可能稳定地抽取出“左片段—linker—右片段”结构关系。

其次，围绕 linker 中间单元设计表示方法。本文不直接对整段 linker 进行硬建模，而是通过对 linker 主链的切分，将其转化为具有连接语义的 token 序列，并在此基础上学习中间单元 embedding，从而缓解长尾分布带来的建模困难。

再次，采用 token-based 条件生成方法进行建模。模型以左右 fragment 的二维条件信息为输入，以 linker token 序列为生成目标，在固定长度表示空间内完成条件生成，并通过 PAD 学习和停止机制控制输出序列边界。

最后，通过多维实验评估生成结果，包括生成成功率、分子性质分布、结构空间覆盖和相似性分析等，从而判断该方法在当前任务设定下的有效性与局限性。

### 1.4 主要工作与贡献

本文的主要工作可以概括为以下三个方面。

第一，构建了一套面向 PROTAC linker 条件生成的弱监督数据处理流程。针对原始 PROTAC 数据中缺乏 linker 级强监督标注的问题，本文通过化学子结构匹配与规则筛选，将完整分子转化为适用于条件生成任务的 weak-anchor 样本。

第二，提出了一种围绕 linker 中间单元的分阶段表示学习策略。本文从 linker 主链切分出中间结构单元，采用 oriented token 表示连接方向，并通过高频片段建库、低频片段映射和任务微调的方式学习统一 embedding 空间，以缓解长尾结构对建模稳定性的影响。

第三，实现并评估了基于 token 的二维条件生成方案。本文在统一任务设定下比较了图扩散与 token-based 路线，并从性质分布、结构空间覆盖、相似性与多样性等多个维度验证了 token-based 方法在当前 PROTAC linker 任务中的适配性。

## 第2章 任务定义与数据构建

### 2.1 任务定义

本文关注的是二维条件下的 PROTAC linker generation 问题。给定左右功能片段及其对应的二维结构条件信息，目标是生成能够连接这两个片段的中间 linker，或者进一步恢复为完整的连接结果。与需要显式建模三维相对构象的 pose-aware generation 不同，本文不假设存在可靠的 fragment 三维姿态信息，而是仅利用二维结构信息开展建模。

在这一设定下，输入主要包括左右功能片段的结构表示、anchor 相关信息以及由训练数据推导出的 linker 条件目标；输出则是 linker 的生成结果，或者能够成功解码并组装回完整 PROTAC 的连接结果。该设定更加贴近当前公开 PROTAC 数据的可用形式，也为后续采用二维 token 表示提供了基础。

### 2.2 原始数据来源与预处理

本文使用的原始数据由完整 PROTAC 分子集合与候选 linker 分子集合两部分构成。完整 PROTAC 数据提供了分子总体结构，而 linker 数据提供了候选连接子分子。由于二者并非天然一一对应，且表格级 ID 并不能直接作为监督对齐依据，因此必须借助化学结构匹配对样本关系进行重建。

在预处理阶段，首先对原始分子进行结构解析与 canonical 处理，去除无效分子、重复分子和明显异常样本，保证后续匹配步骤建立在可靠分子表示基础上。随后，对完整 PROTAC 分子与 linker 候选分子进行格式统一，包括 canonical SMILES 标准化、基础原子和键类型检查等，以减少同构表示差异带来的干扰。

对于异常样本，本文采取保守处理策略。对于无法解析、无法 sanitize 或子结构匹配不明确的样本，均在数据构建阶段予以剔除，而不是强行保留到训练中。这样做的主要考虑是，在当前数据量下，样本质量对模型稳定性的影响高于单纯追求样本规模。

### 2.3 weak-anchor 样本构建

从完整 PROTAC 分子构造条件生成样本，是本文数据部分的核心工作。由于原始数据只给出了完整分子和候选 linker 集合，而没有直接提供 linker 在完整分子中的精确对应关系，因此本文采用基于化学子结构匹配的 weak-anchor 策略来构造训练样本。

具体而言，对每一个候选 linker 分子，尝试在完整 PROTAC 分子中进行子结构匹配，并结合一系列规则筛选高置信样本。样本筛选规则包括：匹配必须唯一、匹配子图在完整分子中必须连通、linker 边界必须恰好对应两条 crossing bond、两侧 anchor 原子必须不同、切分得到的 linker 和左右片段必须满足最小规模限制，并且各部分在结构上能够成功 sanitize。通过这些约束，可以排除匹配模糊、边界不清晰或片段规模过小的样本，从而获得更稳定的弱监督样本集。

在完成切分后，每个有效样本被表示为“左片段—anchored linker—右片段”的三元结构，其中 anchored linker 保留连接位点信息，用于后续 token 化表示和条件生成建模。这样，原本无法直接用于训练的完整 PROTAC 数据，就被转化为适用于 linker 条件生成的样本集合。

需要强调的是，weak-anchor 数据集并不意味着每个样本都具有严格的人为标注真值，而是通过化学规则尽可能从原始数据中抽取高置信结构关系。因此，这一数据集是“弱监督但可训练”的，而不是“完全无监督”的。

### 2.4 数据分布分析

在完成 weak-anchor 数据构建后，本文进一步分析了样本分布特征，以指导后续的表示设计和模型选择。首先，从 linker 长度、分子量和可旋转键数量等指标来看，PROTAC linker 相比普通小分子连接子整体更加多样，且存在从较短柔性链到较长复杂连接子的广泛变化范围。这说明仅依赖简单模板难以覆盖任务空间。

其次，对 linker 中间结构单元的频率统计表明，数据中存在明显的头部—长尾分布。少数高频结构在样本中重复出现较多，而大量中低频结构仅出现少量次数。这意味着若直接对整段 linker 或全部 token 进行统一学习，模型往往更容易被高频结构主导，导致对稀有结构模式的表达不足。

再次，从 weak-anchor 数据和原始 linker 库的对比可见，经过样本筛选后得到的训练 linker 分布已经发生任务化偏移。这种偏移并不是噪声，而是由“必须能够在完整 PROTAC 中形成合理连接”这一任务要求自然引入的。因此，后续模型应当学习的是 weak-anchor 训练分布，而不是原始 linker 库的整体分布。

综上，本章得到两个自然结论。第一，原始 PROTAC 数据不能直接作为标准 linker 条件生成监督，需要通过 weak-anchor 流程进行结构化重建。第二，linker 中间结构存在明显长尾性，因此后续建模必须引入更适合该任务的中间层表示。

## 第3章 面向 linker 中间单元的表示学习方法

### 3.1 表示设计动机

在当前任务中，直接将整段 linker 作为最小建模单元存在明显问题。由于完整 linker 的组合空间很大、结构模式多样，整段 linker 直接建模会导致样本空间过于稀疏，不利于模型稳定学习。同时，若直接采用原子级表示，虽然表达能力较强，但中间结构模式需要由模型在更低层级自行归纳，容易增加训练难度。

此外，数据分布分析表明，linker 中间结构单元存在显著长尾：常见结构模式出现频繁，而大量稀有结构只出现很少次数。这种分布特点意味着，仅靠统一的端到端学习很容易让模型集中在头部高频模式上，而忽略中低频结构的可学习性。

基于上述考虑，本文不直接对整段 linker 或单个原子进行硬建模，而是引入“linker 中间单元”这一中间层表示。该表示既保留了 linker 的主要结构模式，又避免了整段 linker 空间过于稀疏的问题，从而为后续稳定生成提供了更适合的建模层级。

### 3.2 linker 中间单元切分与 token 化

围绕 linker 中间单元表示，本文首先对 linker 主链进行切分。切分的目标不是简单断开所有键，而是在保留主要连接语义的前提下，将 linker 分解为一组可重复出现、可学习的结构单元。对于包含明确 attachment 信息的结构，token 在定义时保留连接位点，而不是将其视为普通子结构片段。

在此基础上，本文进一步引入 oriented token 表示。普通 token 只描述“这个中间单元是什么”，但对于具有两个连接端且本身不对称的片段，仅保留结构本身会丢失左右连接方向信息，从而在解码时产生歧义。通过 oriented token，可以显式区分片段在 linker 序列中的方向角色，使得同一个结构单元在不同连接方向下具有可区分的表示。

为了便于统一建模，本文将 linker token 序列嵌入到固定长度表示空间中，并通过 PAD 机制对较短样本进行补齐。这样，linker 不再以可变长原子图形式输入模型，而是转化为定长 token 序列的连续 embedding 表示，为后续扩散式或序列式条件生成提供了统一接口。

### 3.3 分阶段 embedding 学习策略

在 token 化之后，如何学习稳定的 linker 中间单元表示是本章的重点。针对数据的长尾问题，本文采用分阶段 embedding 学习策略，而不是一次性在全词表上进行统一训练。

第一阶段，在高频片段上建立基础 embedding 空间。高频 token 在数据中具有更充分的上下文共现信息，适合作为表示空间的“骨架”。通过先在这些常见结构单元上学习 embedding，可以获得一个较稳定的结构语义空间。

第二阶段，对低频片段进行映射与初始化。对于数据中出现次数较少的片段，若完全独立训练，容易受到样本不足影响。为此，本文根据结构相似性和化学规则，将低频片段映射到已有 embedding 空间中的近邻结构，以减轻稀疏样本带来的不稳定性。

第三阶段，将上述表示空间与真实 linker 样本结合，进行任务微调。此时 embedding 不再只描述局部片段共现关系，而是逐渐适应下游 PROTAC linker 生成任务。通过这一分阶段策略，模型学习的不是一个孤立的词表，而是一个既反映结构语义、又服务于下游生成的中间表示空间。

因此，本文解决长尾问题的方式，不是简单丢弃低频结构，而是先构建稳定骨架，再逐步将低频结构纳入统一表示空间中。这也是后续 token-based 生成能够稳定运行的重要基础。

### 3.4 条件信息编码

在生成任务中，中间单元 embedding 只是被生成的主体，而左右 fragment 和 anchor 信息构成条件输入。为此，本文将左右 fragment 作为条件分支输入模型，由条件编码模块提取其结构特征；同时，将 anchor 相关信息融入 linker token 序列的表示和解码流程中，使模型能够知道 linker 应当在什么样的连接条件下生成。

具体而言，左右 fragment 的编码承担“上下文约束”作用，中间单元 embedding 则承担“生成内容空间”作用。二者在模型中并不是替代关系，而是条件与目标的分工。通过这种方式，模型能够在保持 linker 序列可学习性的同时，利用左右片段信息对生成结果进行条件约束。

本章的核心结论是：本文并不是直接对原始 linker 进行硬建模，而是通过中间单元表示和分阶段 embedding 学习，提高了 PROTAC linker 在当前二维弱监督场景下的可学习性和建模稳定性。

## 第4章 基于 token 的 PROTAC linker 条件生成方法

### 4.1 生成模型总体框架

在获得 linker 中间单元的 token 表示与 embedding 空间之后，本文进一步构建基于 token 的 PROTAC linker 条件生成方法。该方法以左右 fragment 的二维条件信息为输入，以 linker 的有序 token 序列为生成目标，在连续 embedding 空间中完成条件生成，再通过 token 解码恢复为可组装的 linker 结构。

从整体流程上看，模型首先接收左右 fragment 条件，对其进行编码；随后，在固定长度 token 表示空间中，对 linker token embedding 进行建模与生成；最后，通过最近邻解码、停止机制和结构后处理，将生成结果映射回离散 token 序列，并进一步恢复为 anchored linker 乃至完整 PROTAC 结构。

与原子级图生成相比，这种方案的优势在于：生成对象从原子与边转变为具有结构语义的中间单元序列，从而降低了任务难度，并使模型能够更稳定地学习 linker 的整体结构模式。

### 4.2 停止机制与 PAD 学习

在固定长度表示空间中，模型不仅需要生成 linker 的结构内容，还需要学会在合适的位置停止。为此，本文引入 PAD 机制，使不同长度的 linker 都能够嵌入统一长度空间中。PAD 在这里不只是补齐符号，也承担“停止位置”语义。

在实际训练中，模型学习的不是任意长度序列，而是在固定长度空间内预测哪些位置是真实 token，哪些位置应当为 PAD。因此，停止机制本质上对应于模型是否能够正确学习“从何处开始进入尾部补齐”。这一机制会直接影响生成序列的长度分布，并进而影响生成 linker 的结构性质分布。

基于这一认识，本文进一步将 pad suffix CE 约束作为控制变量，引入到训练目标中，用于收紧停止语义。该约束并不改变整体模型范式，而是对“第一个 PAD 之后应持续为 PAD”这一行为进行额外监督。本文将其视为对停止机制的一个实验控制项，用于观察停止约束如何影响生成风格和分布特性。

### 4.3 训练目标与采样方法

本文的生成模型在连续 embedding 空间中进行训练，基础目标是学习在条件输入下恢复 linker token embedding 的结构信息。在此基础上，可加入辅助的 token 级语义约束，用于提升离散 token 边界和停止语义的一致性。

在采样阶段，模型在固定长度 embedding 空间中逐步生成 linker 表示，再通过与词表 embedding 的相似度匹配恢复离散 token。随后，结合 PAD 停止机制对序列进行截断，并通过结构解码与组装过程恢复为最终 linker 结果。后处理步骤进一步负责检查生成结构是否可解码、是否可组装回完整分子，以及是否满足基本的分子合法性要求。

通过以上设计，本文实现了一套可在二维条件下运行的 token-based PROTAC linker 生成模型，并为后续实验比较提供了统一的主方法框架。

## 第5章 实验设计

### 5.1 实验设置

实验部分围绕 weak-anchor 数据集开展。首先，对构建得到的样本进行训练集、验证集和测试集划分，并在统一数据条件下训练不同版本的生成模型。为了保证实验可比较性，本文在主实验中统一采用相同的数据预处理流程、固定长度 token 表示空间和一致的采样策略。

模型配置方面，本文以 token embedding 维度、条件编码结构和停止机制约束作为主要可调因素。训练中记录模型在训练集和验证集上的损失变化，并在采样后结合结构解码、组装和性质分析评估结果质量。

在推理阶段，模型针对给定左右 fragment 条件生成若干 linker 候选，并对生成结果进行解码与后处理。对于不可解析、不可组装或不满足基本分子合法性的结果，视为生成失败样本。其余结果进入性质与结构分布分析阶段。

### 5.2 评价指标

为了全面评估生成结果，本文从端到端生成指标、分子性质指标以及结构空间与相似性指标三个层面进行分析。

端到端生成指标主要衡量生成流程本身是否闭环，包括 parse success rate、decode success rate、assemble success rate 以及 valid full molecule rate。该类指标回答的是模型能否稳定生成并恢复为合法结构。

分子性质指标用于衡量生成结果是否在理化性质上接近训练任务空间，主要包括 heavy atoms、分子量（MW）、rotatable bonds、QED、SA、logP 和 TPSA 等。通过比较生成集与训练集的性质分布，可以判断模型是否学到了任务数据的粗粒度结构规律。

结构空间与相似性指标用于评价生成结果在结构覆盖与多样性上的表现。本文采用 Morgan fingerprint 的降维可视化方法（如 t-SNE 或 PCA）观察生成样本与真实样本在结构空间中的分布关系，并通过 nearest-neighbor Tanimoto similarity、uniqueness、novelty 和 internal diversity 等指标分析生成结果与训练集之间的关系。

上述三类指标共同作用，使本文不仅能回答“模型能不能生成”，还能够回答“生成结果是否接近真实分布、是否具有多样性、以及是否只是训练集样本的重复”。

结合当前实验，本文最终采用的主要比较对象包括：弱监督训练集（train）、原始 anchored linker 库（raw linker）、16 维 token 主模型（gen_16d）、32 维 token 模型（gen_32d）、两种不同 PAD 语义约束版本（gen_pad_suffix_ce005 与 gen_pad_suffix_ce015）以及外部 baseline Link-INVENT。各模型和基准的统一统计结果见表 6-1；相应的性质分布图、最近邻相似性分布图以及 Morgan fingerprint 空间可视化图则分别见图 6-1 至图 6-4。

## 第6章 实验结果与分析

### 6.1 主方法生成结果

首先，本文评估 token-based 主方案在当前任务中的基本生成能力。从端到端流程来看，该方法能够在二维条件下完成 linker 的生成、解码与组装，说明方法整体是成立的。相较于前期尝试的图扩散路线，token-based 方法在生成稳定性上表现更为可靠，能够较完整地闭合从条件输入到结构输出的整条链路。

在本文当前主设置下，16 维 token-based 模型在 128 个生成样本上实现了 1.000 的 parse success rate、1.000 的 uniqueness、0.953 的 novelty 和 0.814 的 internal diversity；同时，其相对训练集的平均最近邻 Tanimoto 相似度为 0.576，说明模型在保持较高新颖性的同时，仍然能够维持与训练空间的合理接近关系。从端到端流程上看，该模型同时实现了 1.000 的 decode success rate 与 1.000 的 assemble success rate，表明从左右条件输入到 anchored linker 再到完整结构恢复的流程是稳定闭合的。

从分子性质分布来看，主方法生成结果在 linker 长度、分子量和可旋转键等粗粒度指标上能够反映训练集的主要结构趋势。具体而言，训练集 anchored linker 的平均重原子数、平均分子量和平均可旋转键数分别为 15.70、221.16 和 9.03，而 16 维主模型对应结果分别为 14.15、201.35 和 8.68，说明模型已经学习到 PROTAC linker 的核心外层分布规律，但整体仍略偏向更轻、更短的连接子。进一步地，通过结构空间可视化分析可观察到，生成结果并非完全脱离训练空间，而是在真实 linker 结构附近形成具有一定扩展性的覆盖区域。

### 6.2 不同版本比较

在主方法基础上，本文进一步比较不同表示维度和停止机制设计对生成结果的影响。例如，可以比较不同 embedding 维度设置下模型在生成多样性、分布贴合度和结构稳定性上的差异；也可以比较是否引入 pad suffix 约束、不同 PAD 停止语义控制下生成结果的变化。

实验表明，不同版本在长度分布、停止位置和生成风格上会表现出明显差异。首先，从 16 维与 32 维表示维度比较来看，32 维版本在新颖性上达到 1.000，但相对训练集的平均最近邻相似度下降到 0.478，且平均分子量上升到 258.79、平均可旋转键数上升到 11.86，说明表示容量增大后模型更倾向于生成更长、更重、更柔性的 linker。结合图 6-3 可见，32 维版本在结构空间上相对 16 维版本偏离训练集更明显，因此其更适合作为探索较长 linker 空间的扩展版本，而不宜直接替代当前主模型。

其次，从 PAD 停止语义约束的消融来看，较弱的约束版本（ce005）在均值分布上相对训练集较为接近，例如其平均分子量为 215.50，接近训练集的 221.16，同时平均最近邻相似度为 0.527，仍能保持一定贴合度；但其唯一性下降到 0.969，且 SA 提升到 4.472，表明温和约束虽然改善了部分性质分布，却没有在综合质量上显著优于 16 维主模型。较强的约束版本（ce015）则表现出更明显的分布漂移：平均分子量升至 294.67，平均最近邻相似度下降到 0.399，internal diversity 提升到 0.874，说明过强的尾部语义约束会将模型推向更大、更复杂的结构区域。

因此，PAD 相关约束更适合作为“停止机制消融变量”来理解，而不应简单被视为单向度的性能增强项。它的意义在于帮助分析生成边界如何影响整体分布和风格，而不是孤立地追求某个单一指标最优。当前实验结果支持将无额外 PAD 语义约束的 16 维版本作为默认主模型，将 32 维版本和不同 pad suffix 版本保留为控制变量或扩展实验。

### 6.3 与 baseline 的比较

为了验证本文方法在当前任务设定下的合理性，本文进一步与外部 baseline Link-INVENT 进行比较。由于 Link-INVENT 与本文方法同样属于二维 linker generation 范式，因此在当前缺乏稳定三维先验的设定下，其比较更具可比性。

实验结果表明，Link-INVENT 在部分传统药化指标上表现较优，例如 QED 更高（0.687）且 SA 更低（3.829），说明其生成结果更接近常规小分子 linker 的理化风格。然而，从结构分布和任务适配性角度看，Link-INVENT 更倾向于生成较短、较刚性的 linker：其平均可旋转键数仅为 2.34，而 16 维主模型为 8.68，训练集为 9.03。这说明 Link-INVENT 更偏向“小而刚”的小分子 linker 先验，而本文方法在 linker 长度、柔性和结构空间覆盖上更贴近当前 PROTAC linker 训练分布。

从结构空间可视化和最近邻相似度分析来看，本文方法在保持合理相似性的同时，通常能够覆盖更宽的结构区域，体现出更强的任务适配性与多样性。16 维主模型的平均最近邻相似度为 0.576，而 Link-INVENT 为 0.423；同时，16 维主模型的 uniqueness 为 1.000，而 Link-INVENT 为 0.935。结合图 6-5 可见，Link-INVENT 在 fingerprint 空间中形成更集中的簇，而 16 维主模型在训练分布附近表现出更广的覆盖。这说明两类方法的偏好不同：前者更贴近当前任务分布，后者更偏向常规小分子 linker 风格。

### 6.4 结果讨论

综合实验可以得到以下几点认识。

首先，token-based 方法能够学习真实 PROTAC linker 的主要结构模式，并在当前二维条件下实现较稳定的条件生成。与前期图扩散方案相比，它更适合作为当前任务的主生成路线。特别地，16 维主模型在 parse、decode 和 assemble 三个关键端到端环节上均达到 1.000，说明其已经能够稳定承担当前二维弱监督 PROTAC linker 生成任务的主模型角色。

其次，停止机制会显著影响 linker 长度分布和性质分布。PAD 学习和相关约束不仅影响生成边界，还会间接影响 linker 的整体风格，因此应作为生成机制中的关键控制变量加以分析。当前结果表明，停止机制并不存在对所有指标都统一有利的“最强版本”，而更适合作为影响生成风格的调节项。

再次，与 Link-INVENT 的对比表明，本文方法与 baseline 并非简单的“强弱关系”，而是偏好不同的生成分布。Link-INVENT 更集中、更偏向传统药化意义上的“小而漂亮”连接子，而本文方法覆盖范围更广，更贴近当前 PROTAC linker 任务空间。因此，本文方法的优势不主要体现在传统小分子药化指标上，而更多体现在对 PROTAC linker 柔性与任务分布的保持能力上。

最后，尽管本文方法在结构稳定性和任务适配性上取得了较好结果，但在部分药化性质指标上仍存在不足。例如，16 维主模型的平均 QED 为 0.417、平均 SA 为 4.244，均与训练集（0.529 和 3.636）存在一定差距。这说明当前模型已经较好地学到了结构层面的规律，但对更细粒度的化学质量约束尚未完全掌握，这也是后续进一步研究的重要方向。

## 第7章 结论与展望

### 7.1 工作总结

本文围绕二维条件下的 PROTAC linker 生成问题，完成了从数据构建、结构表示到条件生成的整体研究工作。

首先，本文构建了一套 weak-anchor 数据集，通过化学子结构匹配和规则筛选，将原始完整 PROTAC 数据转化为可训练的 linker 条件生成样本，解决了原始数据无法直接用于监督学习的问题。

其次，本文提出了围绕 linker 中间单元的表示与分阶段 embedding 学习策略。通过 token 化、oriented token 表示和分阶段 embedding 学习，提升了模型在长尾结构条件下的可学习性与稳定性。

最后，本文实现并验证了基于 token 的二维条件生成方案。实验表明，在当前弱监督和二维条件设定下，该方案比原子级图扩散路线更稳定，并在任务适配性方面表现出较好的效果。

### 7.2 不足与展望

尽管本文方法在当前设定下取得了一定效果，但仍存在若干不足。

第一，当前模型在 QED、SA 等药化性质指标上仍与训练分布存在差距，说明仅靠结构表示和条件生成尚不足以完全约束生成质量。未来可考虑引入显式性质约束、重排序策略或奖励信号，以进一步提升化学可用性。

第二，当前停止机制虽然能够在固定长度空间中学习 linker 边界，但其设计仍较为粗粒度。后续可进一步研究更细致的停止策略，以更好控制生成长度和尾部语义。

第三，本文工作建立在二维条件设定之上，尚未显式建模真实三维构象关系。未来若能获得更可信的 PROTAC 三维先验或 pose 数据，可进一步将本文方法扩展到结合二维与三维信息的条件生成场景中。

综上，本文工作为二维条件下的 PROTAC linker 生成提供了一套可行的数据与方法流程，也为今后进一步引入性质约束和结构先验奠定了基础。
